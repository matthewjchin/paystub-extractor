# paystub-extractor

Downloadable Python code that allows users to customize regex formatting to write periodical paystub earnings and deductions into spreadsheet form. 

Best for users who are comfortable editing Python code and adjusting their own regex characters.

Write in data or other details from a PDF document and extract your paystub's earnings, deductions, and take-home pay into an editable Microsoft Excel (.XLSX) spreadsheet file. 

This code must be run in a text editor or IDE to allow for easy access to view the recently written numbers into the desired spreadsheet.
